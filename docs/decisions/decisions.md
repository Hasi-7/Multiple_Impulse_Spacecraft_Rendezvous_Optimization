# Decisions

| Time | Decision | Reason | Tradeoff |
|---|---|---|---|
| 2026-10-27 | Add the Sun/Earth/Moon/Jupiter model as standalone `celestial_body_simulator.py`, without changing spacecraft code or the in-progress `Multiple_Gravitational_Objects.py`. | Keep the requested body propagation independent of rendezvous optimization and preserve existing user changes. | Run the body simulation separately; it is not coupled to spacecraft dynamics. |
| 2026-10-27 | Integrate mutual 3D Newtonian gravity with a moving Sun, initially at the origin, then plot Sun-relative positions. | Account for all four bodies' accelerations while retaining Sun-centered visualization; use DOP853 with rtol=1e-6. | The isolated point-mass model omits other planets, relativistic effects and extended-body effects, so it is not a replacement for full Horizons ephemerides. |
| 2026-10-27 | Update the user's new 3D rendezvous plots with full xyz separation and time-matched Sun/Earth-relative views, sharing the precomputed body solution. | The user now requested graphing integration with their new rendezvous system; plotting in the fixed initial origin would obscure Earth-relative motion. | Global and local views are separate; Earth/Moon are visually tiny at AU scale. |
| 2026-10-27 | Draw body surfaces at physical spherical radii using shared `BODY_RADII`, with equal x/y/z scale and bounds that include surfaces. | Prevent misleading body sizes and clipping; distinguish true-scale surfaces from visibility markers. | Radii affect visualization only; point-mass dynamics and collision handling remain unchanged. |
